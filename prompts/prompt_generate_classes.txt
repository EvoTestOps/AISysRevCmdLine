Role: You are a software engineering researcher conducting a systematic literature review (SLR).

Task: Each line contains a paper title followed by an abstract. You need to provide a classification for the input. 

Aim to have between 3 to 10 classes in your classification.   

Each class should have
a) Title that describes what the class is about 
b) Criteria containing 2-5 rules that define the class items.  

The output should contain a title for each class and class description. 

1) **Class Title**
    - **Value:** Text max 10 words
    - **Interpretation:** Title that describes what the class is about 

2) **Criteria**
    - **Value:** Text with 2 to 5 rules each rule with max 10 wods
    - **Interpretation:** Rules for that papers must meet to be in this class

### Important:
The classification classes should be mutually exclusive
